# DeepPalm Supplementary Data

This repository contains supplementary datasets and validation records associated with Deep-Palm.

## Files

### `DeepPalm_positive_sites.csv`
Site-level records for positive S-palmitoylation sites used in model development and evaluation.

### `DeepPalm_candidate_negative_sites.csv`
Site-level records for candidate-negative cysteine sites used in model development and evaluation.

### `DeepPalm_subgroup_statistics.csv`
Sample sizes, positive and negative counts, AUROC values, and 95% confidence intervals for subgroup analyses.

### `DeepPalm_species_heldout_balanced_split.csv`
Records used for the balanced species-held-out evaluation.

## Related study

Deep-Palm: An integrated deep learning framework for structure-aware prediction of protein S-palmitoylation.
